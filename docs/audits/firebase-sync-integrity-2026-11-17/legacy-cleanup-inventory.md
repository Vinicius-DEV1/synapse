# Legacy Cleanup Inventory

This is a removal queue, not authorization to delete now. No item in this list was deleted during the audit. Remove an item only after its listed data-safety gate passes and the [resolution checklist](./resolution-checklist.md) records the evidence.

| Legacy item | Evidence and risk | Safe removal gate |
| --- | --- | --- |
| Legacy Firestore root documents | Root collections are unscoped; anonymous aggregate reads succeeded before rule deployment. New rules now deny anonymous root reads. The user confirmed that every legacy record belongs to the sole account, but Firebase Auth has zero users and no destination UID exists yet. | Create/sign in to the main Firebase Auth account and unlock the app. Back up the source records, copy them without deleting the root originals, reconcile ciphertext and decrypted content, then retain or delete only after a verified restore. |
| Previous root-copy implementation in [`legacy-migrator.ts`](../../../apps/web-react/src/services/migration/legacy-migrator.ts) | The unsafe root-copy implementation was replaced by local-to-workspace migration.
