## Slash command crosswalk

React defines 31 IDs in `apps/web-react/src/components/notes/components/SlashMenu.tsx`: `text`, `h1`, `h2`, `h3`, `cols2`, `cols3`, `todo`, `bullet`, `callout`, `code`, `page-create`, `page`, `group`, `toggle`, `blockquoteToggle`, `table`, `table-week`, `table-day`, `table-habit`, `question`, `ia`, `divider`, `foco`, `alarme`, `documento`, `agrupar`, `scrap`, `video`, `livro`, `evento`, `habito`. Qt also defines `mermaid` in `NotesRichSlashCommandMenu.qml`.

The existence of an ID in both lists is not proof of parity. `useSlashCommand.ts` has per-command execution and nested selection semantics; Qt divides execution between `NotesRichTextInput.qml`, `Editor.qml`, setup modals, and the block router. The checklist requires comparing each action and its failure path, not merely comparing menu labels.
