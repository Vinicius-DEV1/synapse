# Slash Command Crosswalk

This document compares the command catalog and execution paths in React Web and Desktop Qt. The React catalog is the reference for command IDs, display copy, order, and search keywords. Qt-only Mermaid remains an additive capability.

## Catalog comparison

The Qt menu now follows the React command order and uses the same 31 IDs, titles, subtitles, keyword arrays, and full matcher (ID, title, subtitle, and two-way keyword substring). Mermaid is appended after the React commands. Source sizing now follows React's 288 px width, 320 px height cap, 56 px rows, 33 px header, list padding, cursor-relative overflow placement, and 200 ms fade/4 px reveal. Qt draws icons with native Canvas paths and the shared `AppIcon`; matched-viewport visual review is still required.

## Execution contract

- React deletes the slash query before running an action. Qt does the same, then routes formatting commands through `NotesRichTextCommands.qml`, widget commands through `NotesSlashCommandActions.js`, and page references through `NotesRichPageReferenceFlow.qml`.
- The shared query helper follows React's longest-alias-first extraction behavior. It is used for linked-page search, focus, alarm, event, habit, and Scrap URL arguments. Previously, Qt either retained the command text in setup fields or discarded the Scrap URL.
- Column balancing now delegates to `compute_equal_column_widths()` in Core through the Qt bridge. The former QML-only width choice gave all three children 33.3%, which did not match React's 33.3/33.3/33.4 values.
- Confirmed action mismatch: React `/foco` opens the Focus setup modal and calls `handleStartTimer(tag, description, targetTime)` on submit. Qt currently opens `NotesSetupWidgetsModal` and inserts a paused inline focus widget. React `/alarme` opens `AlarmSetupModal` and saves through `handleSaveAlarm`; Qt creates/selects an alarm and inserts an inline alarm widget. Keep the native architecture while matching the React result; do not close either command until timer/alarm state and note content are compared.
- Qt now draws native equivalents for the React icon concepts in `NotesSlashCommandIcon.qml`, including heading, column, check-square, info, file-plus, and table shapes; other icons delegate to the shared `AppIcon`. These are not Lucide assets; compare stroke geometry, hover/selected colors, and text wrapping at matched viewport before claiming visual parity.
- The event setup is split across `NotesCalendarEventForm.qml`, `NotesCalendarDateTimeFields.qml`, and `NotesCalendarEventOptions.qml`; the generic widget picker is isolated in `NotesSetupWidgetPickerPanel.qml`. `CalendarEventWidget.qml` now writes status through Core and keeps widget color separate from agenda color.
- Source review does not establish runtime parity. Every command still needs insertion-at-start/middle/end, nested editing, caret/focus, undo/redo, failure/cancellation, save/reopen, and React round-trip acceptance.
