# Feature Matrix

## Executive Summary

Android now exposes all 18 canonical top-level route IDs. The Settings route currently persists note font size, spellcheck, Anki card-flip animation, and study tones locally; most React settings categories are still unimplemented. Finance, Files, Calendar, Culture, the Diagrams catalog, Video catalog/folders, Focus completion metrics, Habits, Trash, Notifications, Practice, Anki, Questions, Library, and Notes use typed Core/UniFFI operations for the documented local flows; the active Focus timer and Files duplication also persist through their platform/Core adapters; Home reads the existing stores for agenda, due cards, pinned/recent notes, and Finance totals. Diagram canvas editing, other Compose-local flows, account sync, key management, and encrypted-at-rest coverage remain open.

Several React capabilities are global overlays or editor tools rather than standalone module routes. Android has a Settings route with a small set of local editor and Anki preferences, while Workspaces, Sharing, AI assistance, and account authentication and sync have no native flows. Files now has a local Core-backed explorer and SAF import, but Drive, app-native preview, export, page links, and encryption remain open. Practice now has local session and memory management, but its AI conversation and interview flows remain open. Questions now supports Core-backed battery and multiple-choice CRUD, filtered simulation, a 50-item global attempt history, and question-filtered history; open-answer types, richer completion analytics, and a separate filtered battery browser remain open. Library has a Core-backed catalog, collections, progress, and a manual bookmark/highlight notebook; PDF/EPUB reading and import, reader-linked selection, annotation encryption, and sync remain open. Notes supports an expandable tree, subpage creation, reparenting, ordering, and safe plain-text editing with protected-page safeguards; rich TipTap/Yjs editing, revision UI, general linked-page flows, encrypted editing, and sync remain open. Anki, Questions, Library, Video, and Vault still have materially less feature depth than React.
